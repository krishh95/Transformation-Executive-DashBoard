# Transformation Portfolio Executive Dashboard

Interactive, responsive Streamlit dashboard for monitoring and governing strategic business and digital transformation portfolios.

## Features
- **Executive KPI Cards**: Real-time program counts, cumulative budget vs. spend, burn rate, at-risk project volumes, progress vs. benefit realization gaps, and CSAT scores.
- **Executive Insights**: 4 concise, data-driven observations covering Delivery Risks, Budget Concerns, Value Realization Deficits, and Governance Opportunities.
- **Visualizations**:
  - Delivery Status distribution (interactive donut chart).
  - Budget vs. Actual Spend by Client Sector (grouped bar chart).
  - Milestone Completion vs. Benefits Realization quadrant (with 1:1 parity line).
  - Top operational friction blockers ranking.
  - Regional risk profiles and Initiative capital allocation breakdowns.
- **Responsive Bluish & White Executive Theme**: Clean SaaS styling with high readability and contrast.
- **Audit Register & Export**: Searchable and sortable project drilldown table with instant CSV export.

## Quickstart

Run the dashboard locally:
```bash
python -m streamlit run app.py
```
Open your browser at `http://localhost:8501`.
